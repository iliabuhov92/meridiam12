# Меридиам

Сайт открывается с первой страницы. Нажмите «Исследовать возможности», чтобы увидеть облёт Земли и перейти в галерею V18. Кнопка «Назад» в браузере возвращает на первую страницу.

Для GitHub Pages распакуйте ZIP и загрузите всё его содержимое в корень репозитория, сохранив папки first, second и shared. В Settings → Pages выберите публикацию из ветки main, папка / (root). Если GitHub Pages уже настроен на эту ветку и папку, достаточно загрузить файлы. Адрес опубликованного сайта появится в Settings → Pages.

Для локальной проверки запустите из этой папки `python3 -m http.server 4177` и откройте http://127.0.0.1:4177/. Переход между страницами рассчитан на просмотр через веб-сервер.
